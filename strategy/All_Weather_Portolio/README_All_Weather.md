# 全天候组合策略项目说明

## 🎯 项目概述

本项目实现了一个基于真实数据的全天候组合策略，通过科学的资产配置和定期再平衡，在控制风险的前提下实现稳健的长期收益。

## 📊 核心策略配置

### 🎯 资产配置比例
- **沪深300ETF (sh510300)**: 30% - 股票资产，提供长期增长
- **10年期国债ETF (sh511260)**: 40% - 长期债券，提供稳定收益
- **5年期国债ETF (sh511010)**: 15% - 中期债券，平衡流动性
- **黄金ETF (sh518800)**: 15% - 避险资产，对冲通胀

### 🔄 再平衡逻辑（修正版）
1. **季度检查**: 每个季度检查配置偏离度
2. **5%阈值**: 最大偏离超过5%触发再平衡
3. **修正逻辑**: 先卖出超配资产获得现金，再买入低配资产
4. **现金充足**: 确保再平衡过程不会因现金不足而失败
